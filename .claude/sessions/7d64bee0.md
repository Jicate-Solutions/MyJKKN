### Lessons Learned

- **60-sec config-infra survey rule was broken TWICE in one session** — added repeat-offense escalation clause to `feedback_60sec_config_infra_survey_before_spawn.md`. Treat second violation as hard pause.
- **Branch-after-pull verification** — new memory file `feedback_branch_after_pull_verification.md`. After `git pull jicate main` from non-main feature branch, local working copy can silently end up on a sibling branch (e.g., `feat/telephony-substrate-brand-integrity`). Always `git branch --show-current` after pull/fetch/checkout.
- **Pre-integration URL pattern grep** — new memory file `feedback_pre_integration_url_pattern_grep.md`. Before scaffolding new server for existing client contract, grep BOTH client lib AND consumer routes for URL prefix conventions. Caught at 70-min cost when Railway service shipped without `/clients/:clientId/*` multi-tenant prefix.
- **Subagent-driven /writing-plans pattern validated** — atomic-task subagents with concise reports + writing-plans output shape work cleanly together. Less context bloat than parent-driven, less coordination cost than parallel team.
- **DEPLOY_HOOK_GATE worked** — when I tried to fire the Vercel deploy hook before re-validating against the merged SHA, the hook blocked me with clear "Marker SHA: X / Current SHA: Y" message. Correctly forced re-validation after merge.
- **Institutional-dept-WhatsApp reframe** — Director clarified mid-Round-2 interview: BYOW = staff PERSONAL phone with INSTITUTIONAL dept-issued SIM (not personal WhatsApp). Resolves ban-risk concern (institution-owned account, not personal). Shifts procurement from phones (~₹50k each × 24 = ₹12L) to SIMs (~₹500 each × 24 = ₹12k).
