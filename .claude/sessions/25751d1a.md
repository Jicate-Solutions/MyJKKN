### Lessons Learned (5 new memory entries)

1. **feedback_vercel_cli_cwd_resolution.md** — Vercel CLI uses cwd's .vercel/project.json to resolve project; --scope flag only narrows by team. Chain in single Bash call OR use --cwd flag.
2. **feedback_echo_appends_newline_to_env_values.md** — `echo "" | vercel env add` bakes \n into stored values. Use `printf '%s'` instead. Generic rule for STDIN-reading tools.
3. **feedback_vercel_preview_cant_read_production_env.md** — `vercel deploy` (no --prod) creates Preview, can't read Production-target env vars. Use --prod or duplicate vars to preview target.
4. **SKILL.md Gap 9 + Gap 10 appended** — cwd resolution + echo newline gotchas now in /jicate-booking-deploy SKILL.md (joined the existing 8 gotchas Agent C added earlier).
