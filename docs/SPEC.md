# Startup Studio: Portfolio Intelligence — Specification

> Generated by SDD workflow on 2026-03-26
> Source: `specs/STARTUP-STUDIO-INCUBATION-ENHANCEMENT-SPEC.md` (Phase 1: P0 items)

## Overview

Add Technology Readiness Level (TRL) tracking, structured risk assessment (4M framework: Magic/Market/Management/Money), competitive matrix analysis, and 25+ enrichment fields to the existing NIF pipeline. This transforms the NIF pipeline from a thin stage tracker into a portfolio intelligence system that helps incubator managers make data-driven decisions about startup support, resource allocation, and graduation readiness.

**Who:** Incubator managers (admin/super_admin roles) at JKKN's Nattraja Incubation Forum
**What:** Assess and track technology maturity, startup risks, and competitive positioning for each incubated startup
**Why:** DST/MSH funders require TRL reporting; risk assessment enables proactive intervention before startups fail

## Functional Specification

### User Roles

| Role | Can Do | Cannot Do |
|------|--------|-----------|
| **super_admin** | Full CRUD on all TRL assessments, risk assessments, competitive matrices. View portfolio dashboard. Enrich any NIF candidate. | N/A |
| **admin** | Same as super_admin within their institution | Access other institutions' data |
| **faculty/mentor** | View TRL/risk data for candidates they mentor. Cannot create assessments. | Create/edit assessments, view portfolio dashboard |
| **student** | View their own startup's TRL and risk status (read-only) | Create/edit any assessments |

### Screens / Pages

#### 1. Portfolio Intelligence Dashboard (NEW)
- **URL:** `/startup-studio/portfolio`
- **Who sees it:** admin, super_admin
- **What it shows:**
  - KPI cards: Active startups count, Average TRL, Average risk score, Startups at risk (any dimension < 4)
  - TRL Distribution chart (bar chart: TRL 1-3, 4-6, 7-9 with "valley of death" highlight on 4-6)
  - Risk Heatmap (scatter plot: all candidates plotted by overall risk score, colored by risk level)
  - Top 5 "attention needed" list: candidates with lowest risk scores or stalled TRL
  - Pipeline funnel: identified → screened → shortlisted → incubating → graduated (with counts)
- **Actions available:**
  - Click any candidate to navigate to their detail page
  - Filter by TRL range, risk level, stage
  - Export portfolio summary (future — out of scope for this build)
- **Edge cases:**
  - No candidates exist: Show empty state with "No startups in portfolio yet" message
  - No TRL assessments done: Show "TRL data not yet available" in chart area
  - No risk assessments done: Show "Risk assessments pending" in heatmap area

#### 2. NIF Candidate Detail — TRL Tab (ENHANCED)
- **URL:** `/startup-studio/nif/[id]` (new tab within existing detail page)
- **Who sees it:** admin, super_admin (view for mentors/students)
- **What it shows:**
  - Current TRL level displayed as progress bar (1-9) with level name
  - TRL history timeline (each assessment as a card with date, level, evidence, assessor)
  - "Valley of Death" warning banner if TRL is 4-6 and hasn't advanced in 6+ months
  - Blockers list from latest assessment
  - Link to Solutions Hub product if `sh_product_id` is set
- **Actions available:**
  - "Assess TRL" button → opens assessment dialog/form
  - Assessment form fields: TRL level (1-9 selector with descriptions), evidence description (required), evidence URLs (multi-input), validation checkboxes (lab/env/prototype/system/operational depending on TRL), blockers (tag input), next steps (text), estimated months to next (number)
  - Edit previous assessment (admin only)
- **Edge cases:**
  - No TRL assessments yet: Show "No TRL assessment recorded" with prominent "Assess TRL" button
  - TRL goes DOWN: Allow it (pivots happen) but show warning "TRL decreased from X to Y"
  - Evidence URLs invalid: Client-side URL validation, allow empty array

#### 3. NIF Candidate Detail — Risk Tab (ENHANCED)
- **URL:** `/startup-studio/nif/[id]` (new tab within existing detail page)
- **Who sees it:** admin, super_admin (view for mentors/students)
- **What it shows:**
  - Radar chart with 4 axes: Magic (Technology), Market, Management, Money — each scored 1-10
  - Overall risk level badge: Low (green, avg >= 8), Moderate (yellow, avg >= 5), High (orange, avg >= 3), Critical (red, avg < 3)
  - Per-dimension detail cards showing:
    - Score (1-10)
    - Key sub-indicators (e.g., Magic: TRL level, IP status, tech advisory, prototype maturity)
    - Mitigation plan text
    - Priority risk flag (which dimension needs most attention)
  - Risk trend chart (line chart showing overall risk score over time, if multiple assessments exist)
  - Action items from latest assessment (with status tracking)
- **Actions available:**
  - "Assess Risk" button → opens comprehensive risk assessment form
  - Risk form is organized into 4 sections (one per M), each with:
    - Score slider (1-10)
    - Sub-indicator fields specific to that dimension
    - Notes textarea
    - Mitigation plan textarea
  - Priority risk selector (which M is the biggest concern)
  - Action items input (repeatable: action, owner, due_date)
- **Edge cases:**
  - No risk assessment yet: Show empty radar chart (all zeros) with "Assess Risk" CTA
  - First assessment: No trend data, hide trend chart
  - All scores are 10: Show "Low risk" but still display the radar chart

#### 4. NIF Candidate Detail — Competitive Tab (ENHANCED)
- **URL:** `/startup-studio/nif/[id]` (new tab within existing detail page)
- **Who sees it:** admin, super_admin
- **What it shows:**
  - Table of competitors: name, website, type (direct/indirect/substitute), our advantage, their advantage
  - If attributes JSONB is populated: comparison grid with color-coded cells (green = we win, red = they win)
  - Strategic response notes per competitor
- **Actions available:**
  - "Add Competitor" button → form: name, website, type, attributes (key-value pairs), our advantage, their advantage, strategic response
  - Edit/delete competitor entries
  - Reorder competitors by drag (future — out of scope)
- **Edge cases:**
  - No competitors added: "No competitive analysis yet" with Add button
  - Only 1 competitor: Still show table (no comparison grid needed)

#### 5. NIF Candidate Detail — Enriched Info Section (ENHANCED)
- **URL:** `/startup-studio/nif/[id]` (enhanced existing "Startup Information" card)
- **Who sees it:** admin, super_admin (partial view for students)
- **What it shows:**
  - Expanded startup information card with new fields organized in sections:
    - **Registration:** DIPP number, incorporation number/date, legal structure, GST, PAN
    - **Documentation:** Pitch deck URL (link), elevator pitch (text), business plan URL, logo
    - **Founder Profiles:** JSON array displayed as mini cards (name, role, linkedin, experience)
    - **Market:** Customer count, market sector, target geography
    - **IP:** Patents filed/granted, trademarks
    - **Incubation:** Agreement signed (date), allocated space, equity given
    - **KYC:** Status badge (pending/submitted/verified/rejected), document list
    - **Enthusiasm Curve:** Visual indicator showing current phase
    - **Capital Assessment:** 4-bar chart (Creative, Innovation, Human, Financial capital scores)
- **Actions available:**
  - "Edit Startup Details" button → opens comprehensive edit form with all new fields
  - Each section is collapsible
  - Upload/link pitch deck
- **Edge cases:**
  - All new fields null: Show existing data only (backward compatible)
  - Partial data: Show available fields, hide empty sections

### Scope Boundaries

**In scope:**
- TRL assessment CRUD + history timeline + TRL distribution chart
- Risk assessment CRUD (4M framework) + radar chart + risk trend + action items
- Competitive matrix CRUD + comparison table
- NIF candidate enrichment (25+ new columns) + edit form
- Portfolio Intelligence Dashboard (new page)
- All 3 new services, hooks, API routes following existing patterns
- Database migration with RLS policies
- Type definitions extending existing interfaces

**Explicitly out of scope:**
- Mentor management (Phase 2 of enhancement spec)
- Graduation criteria engine (Phase 3)
- Financial management / grant tracking (Phase 4)
- KPI framework / impact reports (Phase 4)
- Governance / compliance tracking (Phase 5)
- Marketing activity tracking (Phase 6)
- Institutional readiness scorecard (Phase 5)
- Export to PDF/Excel from portfolio dashboard
- Automated TRL assessment suggestions
- Integration with external patent databases
- Notifications/alerts when risk scores drop

### Assumptions

- [ASSUMPTION-1]: Risk assessments are done quarterly + on-demand. No automated scheduling.
- [ASSUMPTION-2]: Portfolio Dashboard is a new page at `/startup-studio/portfolio`, separate from existing NIF pipeline page.
- [ASSUMPTION-3]: TRL/Risk/Competitive tabs are added to the existing NIF candidate detail page (not separate pages).
- [ASSUMPTION-4]: New permissions follow pattern: `startup_studio.portfolio.view`, `startup_studio.trl.manage`, `startup_studio.risk.manage`, `startup_studio.competitive.manage`.
- [ASSUMPTION-5]: Radar chart uses Recharts (already installed: `recharts@^2.15.4`).
- [ASSUMPTION-6]: The NIF candidate detail page switches from a single-card layout to a tabbed layout (Tabs component from shadcn/ui) to accommodate TRL, Risk, Competitive, and Info tabs.

## Technical Plan

### Database Schema

#### Migration: `20260326000001_ss_portfolio_intelligence.sql`

```sql
-- ================================================================
-- Portfolio Intelligence: TRL Tracking, Risk Assessment,
-- Competitive Matrix, NIF Candidate Enrichment
-- ================================================================

-- 1. TRL Assessments
CREATE TABLE ss_trl_assessments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  candidate_id UUID NOT NULL REFERENCES ss_nif_candidates(id) ON DELETE CASCADE,
  trl_level INTEGER NOT NULL CHECK (trl_level BETWEEN 1 AND 9),
  previous_trl INTEGER CHECK (previous_trl BETWEEN 1 AND 9),
  assessment_date DATE NOT NULL DEFAULT CURRENT_DATE,
  assessed_by UUID REFERENCES profiles(id),
  evidence_description TEXT NOT NULL,
  evidence_urls TEXT[] DEFAULT '{}',
  lab_validated BOOLEAN DEFAULT false,
  relevant_env_validated BOOLEAN DEFAULT false,
  prototype_demonstrated BOOLEAN DEFAULT false,
  system_qualified BOOLEAN DEFAULT false,
  operational_proven BOOLEAN DEFAULT false,
  blockers TEXT[] DEFAULT '{}',
  next_steps TEXT,
  estimated_months_to_next INTEGER,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE ss_trl_assessments ENABLE ROW LEVEL SECURITY;

CREATE POLICY ss_trl_assessments_select ON ss_trl_assessments
  FOR SELECT TO authenticated USING (true);

CREATE POLICY ss_trl_assessments_service_all ON ss_trl_assessments
  FOR ALL TO service_role USING (true) WITH CHECK (true);

CREATE INDEX idx_ss_trl_assessments_candidate ON ss_trl_assessments(candidate_id);
CREATE INDEX idx_ss_trl_assessments_date ON ss_trl_assessments(assessment_date DESC);

-- 2. Risk Assessments
CREATE TABLE ss_risk_assessments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  candidate_id UUID NOT NULL REFERENCES ss_nif_candidates(id) ON DELETE CASCADE,
  assessment_date DATE NOT NULL DEFAULT CURRENT_DATE,
  assessed_by UUID REFERENCES profiles(id),

  -- Magic (Technology/IP) Risk: 1=extreme risk, 10=fully de-risked
  magic_score INTEGER NOT NULL CHECK (magic_score BETWEEN 1 AND 10),
  magic_trl_level INTEGER CHECK (magic_trl_level BETWEEN 1 AND 9),
  magic_ip_status TEXT CHECK (magic_ip_status IN ('none', 'trade_secret', 'patent_filed', 'patent_granted')),
  magic_has_tech_advisory BOOLEAN DEFAULT false,
  magic_prototype_maturity TEXT CHECK (magic_prototype_maturity IN ('concept', 'proof_of_concept', 'alpha', 'beta', 'production')),
  magic_notes TEXT,
  magic_mitigation_plan TEXT,

  -- Market Risk
  market_score INTEGER NOT NULL CHECK (market_score BETWEEN 1 AND 10),
  market_customers_validated INTEGER DEFAULT 0,
  market_willingness_to_pay TEXT CHECK (market_willingness_to_pay IN ('unknown', 'interested', 'verbal_commit', 'paid', 'recurring')),
  market_tam_estimate NUMERIC(15,2),
  market_tam_currency TEXT DEFAULT 'INR',
  market_competition_level TEXT CHECK (market_competition_level IN ('blue_ocean', 'few_competitors', 'moderate', 'crowded', 'monopolized')),
  market_notes TEXT,
  market_mitigation_plan TEXT,

  -- Management (Team) Risk
  management_score INTEGER NOT NULL CHECK (management_score BETWEEN 1 AND 10),
  management_team_size INTEGER DEFAULT 1,
  management_has_domain_expert BOOLEAN DEFAULT false,
  management_has_tech_lead BOOLEAN DEFAULT false,
  management_has_business_lead BOOLEAN DEFAULT false,
  management_coachability TEXT CHECK (management_coachability IN ('resistant', 'passive', 'receptive', 'proactive')),
  management_has_advisory_board BOOLEAN DEFAULT false,
  management_notes TEXT,
  management_mitigation_plan TEXT,

  -- Money (Financial) Risk
  money_score INTEGER NOT NULL CHECK (money_score BETWEEN 1 AND 10),
  money_monthly_burn NUMERIC(12,2),
  money_runway_months INTEGER,
  money_funding_raised NUMERIC(15,2) DEFAULT 0,
  money_funding_currency TEXT DEFAULT 'INR',
  money_revenue_monthly NUMERIC(12,2) DEFAULT 0,
  money_has_financial_plan BOOLEAN DEFAULT false,
  money_investor_interest_level TEXT CHECK (money_investor_interest_level IN ('none', 'exploring', 'in_discussion', 'term_sheet', 'committed')),
  money_notes TEXT,
  money_mitigation_plan TEXT,

  -- Computed fields
  overall_risk_score NUMERIC(4,2) GENERATED ALWAYS AS (
    (magic_score + market_score + management_score + money_score) / 4.0
  ) STORED,
  overall_risk_level TEXT GENERATED ALWAYS AS (
    CASE
      WHEN (magic_score + market_score + management_score + money_score) / 4.0 >= 8 THEN 'low'
      WHEN (magic_score + market_score + management_score + money_score) / 4.0 >= 5 THEN 'moderate'
      WHEN (magic_score + market_score + management_score + money_score) / 4.0 >= 3 THEN 'high'
      ELSE 'critical'
    END
  ) STORED,

  -- Action items
  priority_risk TEXT CHECK (priority_risk IN ('magic', 'market', 'management', 'money')),
  action_items JSONB DEFAULT '[]',

  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE ss_risk_assessments ENABLE ROW LEVEL SECURITY;

CREATE POLICY ss_risk_assessments_select ON ss_risk_assessments
  FOR SELECT TO authenticated USING (true);

CREATE POLICY ss_risk_assessments_service_all ON ss_risk_assessments
  FOR ALL TO service_role USING (true) WITH CHECK (true);

CREATE INDEX idx_ss_risk_assessments_candidate ON ss_risk_assessments(candidate_id);
CREATE INDEX idx_ss_risk_assessments_date ON ss_risk_assessments(assessment_date DESC);

-- 3. Competitive Matrices
CREATE TABLE ss_competitive_matrices (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  candidate_id UUID NOT NULL REFERENCES ss_nif_candidates(id) ON DELETE CASCADE,
  competitor_name TEXT NOT NULL,
  competitor_website TEXT,
  competitor_type TEXT DEFAULT 'direct' CHECK (competitor_type IN ('direct', 'indirect', 'substitute')),
  attributes JSONB NOT NULL DEFAULT '{}',
  our_advantage TEXT,
  their_advantage TEXT,
  strategic_response TEXT,
  last_updated DATE DEFAULT CURRENT_DATE,
  updated_by UUID REFERENCES profiles(id),
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE ss_competitive_matrices ENABLE ROW LEVEL SECURITY;

CREATE POLICY ss_competitive_matrices_select ON ss_competitive_matrices
  FOR SELECT TO authenticated USING (true);

CREATE POLICY ss_competitive_matrices_service_all ON ss_competitive_matrices
  FOR ALL TO service_role USING (true) WITH CHECK (true);

CREATE INDEX idx_ss_competitive_matrices_candidate ON ss_competitive_matrices(candidate_id);

-- 4. NIF Candidate Enrichment (ALTER existing table)
ALTER TABLE ss_nif_candidates
  ADD COLUMN IF NOT EXISTS current_trl INTEGER CHECK (current_trl BETWEEN 1 AND 9),
  ADD COLUMN IF NOT EXISTS trl_assessed_at TIMESTAMPTZ,
  ADD COLUMN IF NOT EXISTS enthusiasm_curve TEXT CHECK (enthusiasm_curve IN (
    'uninformed_optimism', 'informed_pessimism', 'valley_of_despair', 'informed_optimism', 'success'
  )),
  ADD COLUMN IF NOT EXISTS capital_assessment JSONB DEFAULT '{}',
  ADD COLUMN IF NOT EXISTS dipp_number TEXT,
  ADD COLUMN IF NOT EXISTS incorporation_number TEXT,
  ADD COLUMN IF NOT EXISTS incorporation_date DATE,
  ADD COLUMN IF NOT EXISTS legal_structure TEXT CHECK (legal_structure IN (
    'proprietorship', 'partnership', 'llp', 'private_limited', 'section_8', 'opc'
  )),
  ADD COLUMN IF NOT EXISTS gst_number TEXT,
  ADD COLUMN IF NOT EXISTS pan_number TEXT,
  ADD COLUMN IF NOT EXISTS pitch_deck_url TEXT,
  ADD COLUMN IF NOT EXISTS elevator_pitch TEXT,
  ADD COLUMN IF NOT EXISTS business_plan_url TEXT,
  ADD COLUMN IF NOT EXISTS logo_url TEXT,
  ADD COLUMN IF NOT EXISTS founder_profiles JSONB DEFAULT '[]',
  ADD COLUMN IF NOT EXISTS customer_count INTEGER DEFAULT 0,
  ADD COLUMN IF NOT EXISTS market_sector TEXT,
  ADD COLUMN IF NOT EXISTS target_geography TEXT,
  ADD COLUMN IF NOT EXISTS patents_filed INTEGER DEFAULT 0,
  ADD COLUMN IF NOT EXISTS patents_granted INTEGER DEFAULT 0,
  ADD COLUMN IF NOT EXISTS trademarks INTEGER DEFAULT 0,
  ADD COLUMN IF NOT EXISTS incubation_agreement_signed BOOLEAN DEFAULT false,
  ADD COLUMN IF NOT EXISTS incubation_agreement_date DATE,
  ADD COLUMN IF NOT EXISTS allocated_space TEXT,
  ADD COLUMN IF NOT EXISTS equity_given_pct NUMERIC(5,2),
  ADD COLUMN IF NOT EXISTS kyc_status TEXT DEFAULT 'pending' CHECK (kyc_status IN ('pending', 'submitted', 'verified', 'rejected')),
  ADD COLUMN IF NOT EXISTS kyc_documents JSONB DEFAULT '[]';

CREATE INDEX IF NOT EXISTS idx_ss_nif_candidates_trl ON ss_nif_candidates(current_trl);
CREATE INDEX IF NOT EXISTS idx_ss_nif_candidates_kyc ON ss_nif_candidates(kyc_status);

-- 5. Updated_at triggers for new tables
CREATE TRIGGER update_ss_competitive_matrices_updated_at
  BEFORE UPDATE ON ss_competitive_matrices
  FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```

### Key Technical Decisions

| Decision | Chosen | Alternative | Why |
|----------|--------|-------------|-----|
| Tab component for detail page | shadcn/ui `Tabs` | Separate pages per section | Keeps all candidate data in one view, matches MyJKKN patterns |
| Risk radar chart | Recharts `RadarChart` | Custom SVG / Chart.js | Recharts already installed and used for analytics |
| Computed risk fields | PostgreSQL GENERATED ALWAYS | Application-level computation | DB-level ensures consistency, no stale data |
| Competitive matrix attributes | JSONB column | Separate attributes table | Different startups compete on different dimensions — JSONB is flexible |
| TRL + enrichment on same migration | Single migration file | Separate migrations | Atomic deployment, all P0 changes land together |
| NIF candidate enrichment | ALTER TABLE (add columns) | New related table | Direct column access is simpler, no JOINs needed for basic info |
