## 1. PUBLISHER PANEL (Third-Party Marketing)

### Features
- Real-time visibility dashboard for publishers/marketing agencies
- Lead Dashboard with delivery tracking, trend identification, lead health/quality monitoring
- Relative Benchmarking: compare delivery against top publishers for a specific institute
- Comparative Benchmarking: measure growth over days, weeks, months
- Application Dashboard: track student journey from inquiry to application submission
- Predictive analytics on lead status breakup
- Applicant data visibility controlled by institution (toggle on/off for publishers)
- Campaign Dashboard: identify top-performing campaigns and best mediums
- Multi-level tracking: stores up to 3 source instances of same lead (Primary, Secondary, Tertiary)
- Duplicate lead attempt detection with source attribution
- Geographical Dashboard: state/city bifurcation of leads
- Geographic relative benchmarking for publishers
- Application bifurcation across states and cities
- Growth measurement over time by geography

### Metrics/KPIs
- Primary Leads count
- Verified Leads count
- Unverified Leads count
- Application Counts
- Enrollment Counts
- Lead trends over time
- Source share percentage (Primary vs Secondary vs Tertiary)
- City-wise contribution
- State-wise contribution
- Percentage change in geographic performance

### Integration Points
- Publisher API integrations
- Campaign tracking across multiple digital agencies

  - Auto-capture replies as leads in CRM

  - Quality Rating gauge (Low/Medium/High)
  - Template types: Welcome message, Payment reminder, Application initiated, Last date announcement
- Smart Automations:
  - Stage-based WhatsApp communication
  - Engagement triggers next actions (stage updates, score updates, counselor assignment)
  - Automated reminders for deadlines, fee payments, interviews, exams
  - Personalized journeys that reduce drop-offs
- In-Chat Forms:
  - Customizable forms inside WhatsApp chat
  - Collect details, preferences, choices without leaving WhatsApp
  - Feedback and surveys after webinars/events
  - Auto-sync to CRM for context-rich follow-ups
- Echo (Live Chat Platform):
  - Two-way conversations beyond static templates
  - Centralized inbox for all WhatsApp replies
  - Filter and track chats: queued, picked, resolved
  - Every exchange tracked in CRM
- Niaa Chatbot Integration:
  - 24/7 automated responses on WhatsApp

- Campaign ROI Tracking:
  - Track campaign contribution to applications and enrollments
  - Funnel visibility from inquiry to enrollment
