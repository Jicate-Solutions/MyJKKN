### Lessons Learned

- **Cosmetic ≠ real impersonation.** A custom preview cookie that the rest of the app's Supabase clients never read is just a banner, not an identity swap. Real swap requires `admin.generateLink` + `verifyOtp` + `setSession` — Supabase's own primitives.
- **Cookie size ceiling kills naive backups.** Serializing chunked auth tokens to JSON in a single cookie regularly exceeds the browser's ~4KB single-cookie limit and gets silently truncated. For "save state across a flow" — re-derive instead of store-and-restore. PR #185 lesson.
- **Audit-log migrations + insert payloads must be re-tested after deploy.** Adding columns + writing to them in 2 separate PRs creates schema drift if one PR forgets. "Row count = 1" is not enough; check that the row's fields are actually populated. Encoded as ship-myjkkn Step 2.7.
- **`process.env.X!` is a compile-time lie.** Local `.env.local` and Vercel prod env drift silently. Always cross-check before declaring shipped. Encoded as ship-myjkkn Step 2.8.
- **Symmetric primitives are simpler.** `/preview/start` and `/preview/end` both use `admin.generateLink` + `verifyOtp` + `setSession` — start for target's email, end for admin's email. Same code path twice; no separate "restore from backup" path to maintain.
