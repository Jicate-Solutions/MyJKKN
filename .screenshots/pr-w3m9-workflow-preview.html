6. Workflow engine — Director-lock R6-Q3

Per-form approval chain (stored in hr_forms.approval_workflow.steps[]):

  [
    { order: 1, label: "HOD approval", required_role: "hod",
      notify_channels: ["in_app", "whatsapp"] },
    { order: 2, label: "Principal sign-off", required_role: "principal",
      notify_channels: ["in_app", "whatsapp"] },
    { order: 3, label: "CAO final approval", required_role: "cao",
      notify_channels: ["in_app", "whatsapp"] }
  ]

Engine progression:
  submitForm()                    → status='in_review', step=1, notify HOD
  advanceSubmission(approve)      → step=2, notify Principal + submitter
  advanceSubmission(approve)      → step=3, notify CAO + submitter
  advanceSubmission(approve)      → status='approved', notify submitter (final)
  advanceSubmission(reject) anytime → status='rejected', notify submitter

Notification templates: platform_policies row
  hr.forms.notification_templates  (Director-editable, supports placeholders
  {form_title}, {submitter_name}, {step_label}, {actor_name}, {reason}).

Channel wiring:
  in_app   → notifications + user_notifications (existing pattern)
  whatsapp → whatsapp-api-client.sendTextMessage to profile.phone_number
  email    → stub (no SMTP infra) — logs warning, falls through
  sms      → stub (no SMS infra) — logs warning, falls through
