### Status: IN PROGRESS - 3/30 items verified & fixed

### Critical Discovery: Schema-Service Mismatch
The core bug across the entire admission module: `lead-service.ts` (and likely other services) was coded against a DIFFERENT schema than what's deployed in the DB.

**Actual DB columns for admission_leads:**
id, learner_profile_id, institution_id, engagement_score, quality_score, combined_score, score_breakdown, conversion_probability, stage, stage_changed_at, previous_stage, assigned_counselor_id, assigned_at, ownership_mode, last_activity_at, last_contact_at, total_messages_sent, messages_this_week, last_message_at, preferred_channel, tags, is_hot_lead, is_priority, parent_name, parent_phone, parent_email, parent_opted_in, interested_programs, preferred_campus, is_active, is_dormant, dormant_at, is_lost, lost_reason, lost_at, created_at, updated_at, created_by, funnel_stage, full_name, email, phone, source, counselor_id, score, score_category, score_updated_at

**Column mapping (code expects vs DB has):**
| Code References | Actual DB Column |
|----------------|-----------------|
| priority (enum) | is_hot_lead (bool) + is_priority (bool) |
| next_followup_at | last_contact_at |
| is_duplicate | DOES NOT EXIST |
| duplicate_of | DOES NOT EXIST |
| program_interest | interested_programs |

### Decisions Made

1. **Schema mismatch fix strategy:** Fix service layer to match actual DB columns (not the other way around)
2. **lead-service.ts createLead:** Simplified to only insert valid DB columns
3. **lead-service.ts getDashboardSummary:** Fixed to use is_hot_lead/is_priority booleans instead of priority enum
4. **lead-service.ts getFunnelSummary:** Fixed same schema mismatch
5. **lead-service.ts getLeads:** Fixed priority filter to use is_hot_lead/is_priority
6. **hooks/admission/index.ts:** Removed `throw error` from two mutation onError callbacks (was causing silent failures)
7. **admission_lead_stage_history table:** Created via migration (was missing)
8. **New lead form payload:** Simplified to 6 essential fields (institution_id, full_name, email, phone, source, tags)
9. **Test data seeded:** 52 leads, 5 counselors, 20 activities, 10 applications, 3 scoring rules, 3 templates, 5 programs
10. **types/admission.ts:** OUT OF SYNC with actual DB schema - needs full audit
